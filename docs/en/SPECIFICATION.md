# EN 公式サイト 仕様書（2026-11 確定版）

最終更新: 2026-11-05。見直し: 料金・ポリシー変更時。

運営者承認済みの予約条件と、サイトの実装仕様をまとめた正本ドキュメント。

## 1. ブランド方針

ENは京都府福知山市観音寺の一棟貸し宿。「縁」をコンセプトに、家族・友人・親族・会社仲間が
集まり時間を共有するための、高級感とプライベート感を持つ宿として位置づける。
価格訴求ではなく、空間の美しさ・快適性・信頼性を伝える。

## 2. デザイン

- 配色: アイボリー×ブラウン×ブラック（--bg-primary #FAF7F2 / --dark-bg #2C2520 / --accent #8B7355）
- フォント: Playfair Display（欧文見出し）+ Noto Serif JP（和見出し）+ Noto Sans JP（本文）
- HERO: 2枚スライド（PC: リビング→寝室 / SP: 暖簾玄関→寝室）、5秒間隔、クロスフェード+微小ズーム
- 写真は実写のみ（AI生成・仮写真は禁止）。セクション別にフレーム規格を統一
  - GALLERY: 統一4:3フレーム+contain（余白は暗背景に同化）
  - ROOMS: 3/2 cover
  - CONCEPT: 4/3
- `prefers-reduced-motion` 対応済み

## 3. 施設情報（掲載値）

- 京都府福知山市観音寺131-1 / 高津駅（JR山陰本線）車5分
- 一棟貸し・最大16名（3歳以上+2歳以下の実人数。エアコン4部屋のみの利用は13名まで）
- チェックイン 15:00〜22:00 / チェックアウト 12:00
- 駐車場3台無料 / BBQセット2,000円 / テントサウナ2,000円 / アーリーチェックイン5,000円

## 4. 料金（確定・運営者承認済み）

| 項目 | 値 |
|---|---|
| 基本宿泊料金 | 48,000円/泊（4名まで・税込） |
| 追加人数料金 | 5名目から6,000円/名/泊（3歳以上） |
| 2歳以下 | 無料（寝具・アメニティなし・有料枠には含めない） |
| 最大 | 16名（実人数。安全管理上の上限の最終確認は運営者） |
| 曜日・季節別料金 | なし |

計算式: 1泊料金 = 48,000 + max(0, 3歳以上人数 - 4) × 6,000
金額は lib/pricing.js に一元管理。変更時はコード修正で対応（管理画面からの料金編集は持たない）。
確定予約には作成時点の金額を保存し、後から料金を変更しても影響しない。

## 5. 予約条件

- 最低1泊/最大30泊
- 予約受付期限: 当日予約可。チェックイン当日の15:00（日本時間）まで受付、期限後はサーバーが拒否（booking_closed）
- 同日チェックアウト/チェックイン可（半開区間 [in, out) 管理）
- 仮予約: 決済中30分間の確保。期限切れは自動解放（遅延実行+Cron）

## 6. オプション

| オプション | 料金 | 扱い |
|---|---|---|
| BBQセット | 2,000円/予約 | 支払方法を選択可 |
| テントサウナ | 2,000円/予約 | 支払方法を選択可 |
| アーリーチェックイン(12:00〜) | 5,000円/予約 | **希望受付のみ**（前日予約・清掃状況で承認制。予約時は徴収しない） |

支払方法（予約時に選択）:
- **online**: 宿泊料+BBQ/サウナをまとめてStripe決済（アーリーは除く）
- **onsite**: 宿泊料のみStripe決済。オプションは現地現金払い
オプションは泊数倍しない（1予約につき）。

## 7. キャンセルポリシー（確定・Airbnb「普通」準拠の自社規約）

チェックイン予定日 D の15:00（日本時間）を基準:

| 区分 | 返金 |
|---|---|
| D-5日 15:00 まで | 宿泊料金100%返金 |
| D-5日 15:00 過ぎ〜D日 15:00 未満 | 1泊目返金なし。2泊目以降は50%返金 |
| D日 15:00 以降（チェックイン後含む） | 宿泊済み泊数+追加1泊分を返金せず、残り未宿泊分の50%を返金（残りがなければ0円） |
| 24時間ルール | チェックイン7日前以上に確定した予約は、確定から24時間以内のキャンセルで100%返金 |

- 宿泊済み泊数は「チェックイン日15:00からの経過時間」からサーバー側で確定（1日未満は1泊扱い）
- 返金対象は予約時の宿泊料金（price_detail）。料金改定の影響を受けない
- オンライン決済オプション（BBQ/サウナ）は提供前のキャンセルで全額返金。チェックイン開始後は自動返金せず運営者が判断
- 現地払いオプション・アーリーチェックイン（未徴収）はStripe返金対象外
- 28泊以上は長期宿泊規約が未確定のため受付不可（maxNights=27）
- 返金実行は管理画面から（部分返金・冪等キー・二重返金防止済み）

## 8. 予約システム

- 4ステップフォーム（日付→お客様情報→確認→完了）
- データベース: Neon Postgres（bookings/blocked_dates/settings/email_log/admin_log/admin_users）
- 二重予約防止: トランザクション内の行ロック+半開区間照合（実DBでの並列テストを推奨）
- 決済: Stripe Checkout（カードのみ）。Webhook が正式な確定経路（ブラウザ戻りに非依存）
- 予約番号: EN-XXXXXXXX-XXXX 形式。確定予約には金額・内訳を保存（料金変更の影響を受けない）

## 9. メール

- 確定時: 宿泊者向け（予約番号・日程・金額・現地支払予定・住所・チェックイン案内）+ 運営者向け
- お礼メール: チェックアウト翌日（Cron・1回のみ）
- 送信はサーバー側（EmailJS REST）。結果をDB記録し管理画面から再送可能

## 10. 管理画面

/admin/（サイト管理者・施設オーナーの2アカウント。権限は同一）
- 予約一覧（検索・フィルタ）/ 詳細 / 月表示カレンダー（前月・翌月・今月移動、セルクリックで日別詳細、斜線=受付停止）/ 受付停止 / 手動予約（知人向け・現地精算）
- キャンセル / ポリシー準拠のStripe返金 / メール再送 / キャンセルポリシー設定 / 売上分析
- 手動予約はオンライン売上に含めない（現地精算として分離集計）。予約一覧の「入金済みにする」ボタンで入金を記録すると、分析の「入金済み売上（オンライン+手動入金）」「入金済み(手動)」に反映される（冪等・二重計上なし）
- WEB予約（オンライン決済）は確定時にオンライン売上へ、現地払い選択時は現地支払予定へ自動集計される
- 操作中はローディングバー表示+ボタン無効化（二重押下防止）。失敗時はエラー理由を日本語で表示
- セッション復帰はDB参照なしの session.check で行い、Neonコールドスタート時でも画面は即表示される
